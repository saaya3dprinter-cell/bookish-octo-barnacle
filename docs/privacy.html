プライバシーポリシー

サービス名：文字起こし（https://mojiokoshi.saaya3dprint.com）
運営：SAAYA 3Dprint（お問い合わせ：info@saaya3dprint.com）

1. このサービスについて

このサービスは、会議や打ち合わせの音声を文字にし、利用者自身のGoogleドライブに保存するためのツールです。

2. 取得する情報と使い方

  • Googleアカウントのメールアドレス：ログインしている人を画面に表示するためだけに使います。
  • Googleドライブへのアクセス（drive.file）：このサービスが作成したファイル（文字起こしのGoogleドキュメント、録音ファイル、フォルダ）だけを作成・読み込み・更新・ゴミ箱への移動をします。利用者がこのサービスで作っていないファイルを見ることはできません。
  • 録音した音声：文字にするため、また話した人を分けるために、Cloudflare社のAIサービス（Workers AI）に送って処理します。処理のためだけに使い、運営者が保存することはありません。

3. 保存場所

  • 文字起こしと録音は、利用者自身のGoogleドライブと、利用者の端末（ブラウザ）の中に保存されます。
  • ログインを続けるための情報は、暗号化して利用者の端末のCookieにだけ保存します。運営者のサーバーには保存しません。
  • スマホとPCをQRコードでつなぐときの中継サーバーは、受け取ったデータをそのまま相手に渡すだけで、保存しません。

4. 第三者への提供

法令にもとづく場合を除き、取得した情報を第三者に提供・販売することはありません。Googleユーザーデータを広告に使うことはありません。

このサービスによるGoogle APIから受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. データの削除

  • 文字起こしや録音は、利用者がGoogleドライブの「文字起こし」フォルダから、いつでも削除できます。
  • このサービスのアクセス権は、Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも取り消せます。また、画面の「ログアウト」でも取り消せます。
